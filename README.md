# シャドバWB シールド戦シミュレーター

Shadowverse: Worlds Beyond のカードパックを**公表排出率どおりに開封**し、
出たカードだけでデッキを組むシールド戦シミュレーターです。

👉 **https://zeki70.github.io/sv_packsimu/**

## できること

- 弾とパック数を選んでカードプールを生成（既定: 最新6弾 × 各8パック = 48パック）
- ベーシックカードを使うかどうかを選択
- 開封結果の内訳表示（レアリティ別・プレミアム・天井までの残りパック数）
- 開いたカードだけで 40枚デッキを構築（1クラス + ニュートラル）
- シードを控えれば**同じカードプールを再現・共有**できる

## シールド戦ルール

Shadowverse: Worlds Beyond に公式のシールド戦フォーマットは無いため、本アプリの独自ルールです。

- デッキは **40枚ちょうど**、**1クラス + ニュートラル**のみ
- 同名カードは通常どおり **3枚まで**（カードごとの上限に従う）
- ただし **開封して実際に手に入れた枚数が上限**。1枚しか出なければ1枚しか使えない
- プレミアム版は同名カードとして通常版と枚数を合算
- ベーシックは開封ではなく、有効時に全種3枚をプールへ追加

## 再現している排出仕様

1パック8枚 = 通常枠7枚 + シルバーレア以上確定枠1枚。排出率は全パック共通です。

| レアリティ | 通常枠 | 確定枠 |
|---|---|---|
| エクスチェンジチケット(4種)※ | 0.060% | 0.060% |
| レジェンド | 1.500% | 1.500% |
| ゴールドレア | 6.000% | 6.000% |
| シルバーレア | 25.000% | 92.440% |
| ブロンズレア | 67.440% | — |

- 各カードは 8.0% でプレミアム版として排出
- ※ チケットは本アプリで意味を持たないため、**プレミアム確定のレジェンド**として排出します
- **レジェンド確定保証（天井）**: 9パック連続でレジェンドが出なければ10パック目の8枚のうち1枚が必ずレジェンド。確定枠は8枚からランダムに選ばれ、8枚目固定ではありません。レジェンド獲得時点で即リセットされ、**カウントは弾ごとに独立**します

出典は `排出率画像/` の公式「カードパック詳細」画面です。

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm test           # Vitest
npm run build      # 型チェック + 本番ビルド
npm run deploy     # ビルドして gh-pages ブランチへ配信
```

### カードデータの更新

カードデータは [shadowverse-scraper](https://shadowverse-wb.com) から取得した内容を軽量化して同梱しています。

```bash
cd ../シャドバ/shadowverse-scraper
node fetch_all_cards.js     # 公式から再取得
node download_images.js     # 未取得の画像だけダウンロード
cd -
npm run sync:cards          # → src/data/cards.json
npm run sync:images         # → public/cards/*.webp
```

新しい弾が追加されても、対象弾は `card_set_id` から動的に決まるためコード変更は不要です。

### 構成

| ディレクトリ | 役割 |
|---|---|
| `src/domain/` | 排出・プール・デッキ検証の純関数。React 非依存、テスト済み |
| `src/data/` | 軽量カードDB と lookup |
| `src/session/` | シードと設定の保存。プールは毎回決定論的に再生成 |
| `src/components/` | 画面 |

乱数は必ず引数で注入し、ドメイン関数が `Math.random()` を直接呼ばない設計です。
これにより排出率が公表値に収束することをテストで検証しています。
